## Techniques
- **Custom slash command as a prompt file** — Create a commands folder in the Claude Code config directory (the exact path is not spoken; the video creates it with a pasted command). Add one .md file per command, e.g. searchweb.md or explaincodebase.md. Write the reusable prompt in the body and use a placeholder for the argument the command will receive. Restart Claude Code so it reads the new file, then invoke it as a slash command with the argument. *When:* A prompt is repeated often, such as a web-search helper or a codebase explainer for onboarding.
- **Claude Code inside Cursor** — Open Cursor's integrated terminal and run `claude`, which detects Cursor and installs the Claude Code extension. Press Cmd+Esc to open the Claude Code panel inside Cursor. Errors from Cursor are passed to Claude Code automatically. For multi-line prompts, run the Cursor-only setup command the video describes (name not spoken) before using Shift+Enter, otherwise Enter submits. *When:* You work in Cursor and want Claude Code next to the editor, with its diagnostics available.
- **Add an MCP server from an existing Cursor or Windsurf JSON config** — Exit Claude Code. Run `claude mcp add-json <name> '<JSON object>'`, where <name> is the server name, ideally matching the config key, and the JSON is the server entry copied from the Cursor or Windsurf config, wrapped in single quotes. Start Claude Code again and run the MCP command to confirm the server is listed as connected. *When:* You already have MCP servers configured for another editor and want the same ones in Claude Code without rewriting them.
- **Use MCP server commands from slash commands** — After an MCP server is connected, type its slash command in Claude Code and supply the argument it asks for. In the Sentry example that is an issue ID for the 'fix issues with Seer' command. *When:* A tool provider offers action-oriented commands, such as fixing a specific issue, that you want to trigger directly without writing the prompt yourself.
- **Plan first, then save rules to CLAUDE.md** — Press Shift+Tab until plan mode is on. Describe the idea and let Claude expand it. When the plan is worth keeping, have it written into CLAUDE.md. Create CLAUDE.md with the init slash command if it does not exist. Use Shift+Tab again to switch to auto-accept edits mode when you want it to edit without asking. *When:* Starting a new project or feature and wanting agreed rules recorded for later sessions.
- **Add 'ultrathink' to a prompt for hard problems** — Put the keyword 'ultrathink' in the prompt. The video recommends it only for problems that Claude fails to solve in normal mode. *When:* A normal attempt has failed on a difficult problem. The video gives no measured benefit, so treat it as a trial.
