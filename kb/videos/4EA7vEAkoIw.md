## Summary
The host demos Talkie, a 13-billion-parameter language model trained on about 260B tokens of pre-1931 English text (newspapers, patents, journals, books), which knows nothing of World War II. The stated motivation is contamination: models trained on the modern web make it hard to tell reasoning from memorized answers, so a model with a date cutoff gives a cleaner test. The demo shows a model that is confused about the internet, gives period slang, and attempts a simple Python task after seeing a few examples in context. The host also covers researchers' forecasting measurements, using surprisingness scores on historical event descriptions. The hard parts of building a pure 1931 model are temporal leakage, poor OCR quality, and post-training with no period data or judge. The researchers used Claude Sonnet 4.6 as the RL judge, which leaked modern chatbot style such as listicles into outputs. They say a GPT-3-level vintage model is in training and that a trillion tokens of historical text would be achievable. Most of the evidence is one-off anecdotal prompts, so the research claims are secondhand.

## Key ideas
- **Talkie is a 13B model trained only on pre-1931 text, so it has no knowledge of WWII or the modern internet** — The host says it is the biggest model of its kind. It confuses the internet with an old US internal revenue tax and gives period slang such as bosh, rot, humbug and fudge. Its predictions of the future are wrong and some are offensive. The host's framing is entertainment first. ([0:00](https://youtu.be/4EA7vEAkoIw?t=0))
- **A date-cutoff model is a contamination-free research tool** — Modern models trained on the web make it hard to tell real reasoning from memorization of a Reddit thread. A model with no post-1931 data removes that confound. The 1931 cutoff comes from US copyright, since works published through 1930 are public domain. ([1:11](https://youtu.be/4EA7vEAkoIw?t=71))
- **In-context learning test: the model learns a new function pattern from a few examples** — Given a few Python examples in the prompt, it sometimes writes working one-line programs. Across 100 tries it passes basic HumanEval-style tests a few times. For a decode function it swaps an addition for a subtraction, which the host reads as understanding inverse functions. The host says a modern model of similar size would do much better. ([2:16](https://youtu.be/4EA7vEAkoIw?t=136))
- **Forecasting can be measured by how surprising post-cutoff events are** — Researchers score the surprisingness of short New York Times 'on this day' event descriptions. Surprise jumps after the 1931 cutoff and spikes in the 50s and 60s. Forecasting skill improves with model size and decays over longer horizons. Post-cutoff patents or papers can test whether a model can invent new ideas. ([3:36](https://youtu.be/4EA7vEAkoIw?t=216))
- **Temporal leakage is the hardest problem to solve in building a pure vintage model** — Talkie sometimes knows who was president in 1936 and some of that president's policies. Possible causes are scans with wrong date metadata, and post-hoc additions such as editorial introductions and footnotes. Data filtering is still being refined. ([4:35](https://youtu.be/4EA7vEAkoIw?t=275))
- **OCR quality is a bottleneck for historical text** — A model trained on OCR'd text reaches only about 30% of the performance of one trained on human-transcribed versions of the same text. Regex cleanup of common errors raises that to about 70%. The team is building a new vintage OCR system. ([4:35](https://youtu.be/4EA7vEAkoIw?t=275))
- **Post-training needs period-appropriate data, and a modern judge brings modern style back in** — There is no ready-made post-training data from the 1930s, so the team wrote instruction data from etiquette manuals, letter-writing guides, cookbooks, dictionaries, encyclopedias, poetry and fables. RL needs a judge, and they used Claude Sonnet 4.6 because no 1930s judge exists. Modern chatbot style leaked in, including listicles. They hope to use vintage models as judges later. ([5:37](https://youtu.be/4EA7vEAkoIw?t=337))
- **Scaling plan: a GPT-3-level vintage model is in training, and a trillion tokens of historical text is said to be achievable** — The host says the researchers believe this would reach original ChatGPT-level capability with 1930s knowledge. This is a stated plan, not a result shown in the video. ([6:37](https://youtu.be/4EA7vEAkoIw?t=397))

## Techniques
- **Contamination-controlled capability probe with a date-cutoff model** — Use a model trained only on text before a chosen cutoff. Put a few worked examples in the prompt (e.g. Python functions), then sample many times (the demo uses 100 tries) and run unit tests. Separate in-context learning from memorization by checking whether the model can solve the held-out variant. *When:* When you need to tell whether a model generalizes or recalls training data. Speaker presents this as demo-level evidence, not a benchmark protocol.
- **Surprisal-based forecasting eval** — Take short event descriptions dated after the model's cutoff and compute how surprising each one is to the model. Track the score across model sizes and forecast horizons. High surprise on post-cutoff events indicates the model cannot anticipate them. *When:* When checking whether a model's forecasting ability is real and how it degrades with horizon length.
- **Temporal leakage audit** — Probe the model with factual questions about events after the cutoff (e.g. who held an office in a given year). Trace leaks to source artifacts: wrong date metadata in scans, editorial introductions and footnotes. Filter those out of the corpus and re-test. *When:* When building any corpus with a hard date boundary, or validating that a date-restricted model really lacks later knowledge.
- **Period-matched synthetic post-training data with a modern RL judge, plus a style check** — Create instruction-following and conversation data from period sources (manuals, cookbooks, dictionaries, poetry). Use a modern LLM as the RL judge because no period judge exists. Then check outputs for modern formats such as listicles, which the judge's style can leak in. *When:* When post-training a model that must not carry modern assistant style, and no period-appropriate data or judge exists.

## Hot takes
- The title's WWII angle is bait. The video is mostly one-off anecdotal prompts with no reproducible eval.
- Research claims (forecasting, surprisingness, the 2018 OpenAI lead-author credential, the trillion-token plan) are secondhand and unsourced in the transcript.
- The in-context code result is weak evidence: the speaker concedes the programs were mostly one-liners and the pass rate is vague.
- Using a modern model as the RL judge is a credible concern: the speaker says style leaked into the 1931 model, which undermines the purity claim.
