> Kai tests Strata, an MIT-licensed local inference engine that runs DeepSeek V4.1 Flash (763B MoE) on a 12GB GPU by tiering experts across GPU, RAM and SSD. Conclusion: it works, but RAM is now the real cost, and the viral 100+ tok/s figure was prefill, not decode.

## Summary
Kai Explains reviews Strata, a local inference engine (MIT, open source, desktop app for Windows, Linux and Mac) that runs large mixture-of-experts models on consumer hardware. Strata places each part of the model by access frequency: the hot core and most-used experts go on the GPU, the next tier in RAM, and rarely used data such as DeepSeek's roughly 110 GB engram table on SSD. Qwen 3.8 Flash Next (125B) runs at about 94 tok/s on a 12GB card and is a usable local assistant. DeepSeek V4.1 Flash runs at only 4-6 tok/s decode on a 12GB card with 64GB RAM, and a viral 100+ tok/s figure was the prefill (prompt-reading) speed. The video's price math shows DDR5 RAM now costs about the same per GB as the VRAM that Strata was built to avoid, so the bottleneck has moved to RAM capacity. Counterintuitively, a 2021 RTX 3060 beat an RTX 5070 on DeepSeek because it had more RAM and faster CPU/storage, and a 2018 MI50 matched an RTX 5090 with the same 32GB. The video recommends renting the API for DeepSeek unless privacy requires local, and gives hardware tiers (16/32/64/128GB) for what runs usably.

## Key ideas
- **Strata runs a 763B MoE model on a 12GB GPU by keeping only the hot part on the card. Experts are tiered by how often they are used: GPU, then RAM, then SSD.** — DeepSeek V4.1 Flash has 40 layers with 384 experts each, and each token activates 6 per layer. Its roughly 196.6B-parameter engram lookup tables (about a quarter of the model, around 110 GB) are read only for specific rows, so they can sit on SSD and be pulled on demand. ([3:58](https://youtu.be/mED-boddeWI?t=238))
- **The viral 100+ tok/s number measured prefill (reading the prompt), not decode (writing output). Decode on the same card was 4-6 tok/s, more than 20x slower.** — Prefill batches thousands of tokens so each expert fetch is amortized across the batch. Decode needs a fresh expert fetch per token, which is why decode from RAM or SSD is slow. ([6:44](https://youtu.be/mED-boddeWI?t=404))
- **At decode speeds the cost of long agent contexts is paid at the start of every task.** — A 30k-token coding-agent prompt takes over 2 minutes of prefill on the 5070 PC with DeepSeek, before the first output token. A 1000-token answer takes about 3.5 minutes at 4.7 tok/s, versus about 11 s for Qwen 3.8 Flash Next at 94 tok/s. ([8:10](https://youtu.be/mED-boddeWI?t=490))
- **RAM is now the expensive tier. The cost of the bottleneck moved rather than disappearing.** — As of late October the video cites: used RTX 3060 12GB at about $310 (~$26/GB VRAM), 64GB DDR5 at about $1,200 (~$19/GB, up from about $191 a year earlier), 2TB PCIe 4 SSD at about $253 (~$0.13/GB). DDR4 64GB is about $500 (~$7.80/GB). The advice is to compare per-GB cost across all three tiers and check how many GB the model needs in each. ([10:50](https://youtu.be/mED-boddeWI?t=650))
- **Speed on DeepSeek depends on how many experts fit on the card, which is a capacity question rather than a GPU-speed question.** — The MI50 kept about 2,700 of 15,360 experts on the card and the 5090 about 1,450 (because it reserved memory for a long context). The MI50 wrote 22-23 tok/s and the 5090 15-25 tok/s. The RTX 3060 (2021, 46GB RAM) ran at 9-11 tok/s on DeepSeek versus 4-6 tok/s for the RTX 5070 PC (64GB RAM). Caveats: different settings, single runs on a warm cache. ([14:44](https://youtu.be/mED-boddeWI?t=884))
- **Qwen 3.8 Flash Next is the model that actually delivers on the 12GB promise. DeepSeek needs 64GB RAM at minimum and 128GB+ to feel usable.** — Qwen Q2 build: about 94 tok/s on the 5070 PC; 28.8 GB lookup table on SSD, about 34 GB of active experts in RAM, about 3.5 GB on the GPU. DeepSeek with 128GB RAM plus a 5070 Ti and fast SSD: 28.8 tok/s at the smallest quantization, dropping to 19 tok/s when spilling to SSD. ([17:23](https://youtu.be/mED-boddeWI?t=1043))
- **Performance settings in fast-moving engines can silently trade quality for speed. Re-check task success, not only tok/s.** — Strata shipped 63 releases in 38 days. One routing shortcut for 12GB NVIDIA cards made code generation 37% faster, but it failed 4.5 of 10 agent tasks (normal: 5.6) and was turned off two days later. Recommended 2-bit quantization kept about 100% of the original's average on several hard reasoning tasks but may need more tokens to think. ([19:48](https://youtu.be/mED-boddeWI?t=1188))
- **For DeepSeek specifically on a 12GB card with 64GB RAM, the API is far cheaper than buying hardware. Local is justified mainly by privacy.** — Off-peak API output is $0.60 per million tokens and peak is $1.20. A $1,200 RAM kit buys about 2B output tokens, which would take roughly 13.5 years at 4.7 tok/s, or about 7 years at the peak API price. Local is the right choice when code cannot leave the machine, such as under client contracts. ([19:48](https://youtu.be/mED-boddeWI?t=1188))
- **Before buying hardware, list your GPU and VRAM, your RAM size and type (DDR4 or DDR5), and your SSD, then match them to a row in Strata's performance table.** — Tiers from the video: 16GB runs Qwen in low-RAM mode pulling experts from SSD (about 8 tok/s on a 3060 with one 16GB stick; a community fork called Betel Juice reports 22 sustained tok/s with a different quantization). 32GB is the Qwen sweet spot (laptop with an 8GB card and 32GB DDR5 reached up to 30 tok/s; a coder build keeps 256 of 512 experts per layer in about 30GB). 64GB fits all Qwen builds. 128GB+ makes DeepSeek useful. ([21:14](https://youtu.be/mED-boddeWI?t=1274))

## Techniques
- **Three-tier expert placement by access frequency** — Rank experts (and engram rows) by how often they are used. Put the hot core and most-used experts on the GPU, the next tier in system RAM, and rarely used data on NVMe SSD, fetched only when a token needs it. Fill the GPU with as many experts as it can hold; the count of experts resident on the card is the main decode-speed driver. *When:* A mixture-of-experts model is larger than VRAM plus RAM can comfortably hold, and most experts are touched only sometimes.
- **Report prefill and decode separately, with context length, quantization and cache state** — Never publish one tok/s number for a local model. Report prompt-processing (prefill) tok/s and output (decode) tok/s separately. State the context length used, the quantization, whether the cache was warm, and whether the number came from one run or several. *When:* Benchmarking local inference or reading a benchmark or viral claim before acting on it. Directly relevant to InferCraft-style benchmark reporting.
- **Per-tier cost math for a hardware decision** — For each tier (VRAM, RAM, SSD), multiply the GB the target model needs in that tier by the current $/GB. Compare the total with the API cost of the same number of output tokens: tokens = budget / price per token; time = tokens / decode tok/s. Example from the video: $1,200 at $0.60 per M output tokens is about 2B tokens; at 4.7 tok/s that is about 13.5 years of writing. *When:* Deciding between buying hardware, renting an API, or running locally for a model at a given size.
- **Quantization and KV-cache choices for large local models** — Use the smallest quantization that still passes your evals. The video recommends 2-bit weights for DeepSeek V4.1 Flash, and a 4-bit KV cache was used on the 128GB build. Re-check task success after every engine release; a speed gain can come with a regression. *When:* Squeezing a large model into limited memory on consumer hardware.
- **Reduced-memory mode and specialized builds** — Use Strata's low-RAM mode to stream experts from SSD (Qwen on 16GB). Use the coder build, which keeps 256 of each layer's 512 experts and needs about 30GB, when the target is code generation. Pick a smaller sibling model (the Qwen 35B-class model, transcribed as 'Quen 3.635B') if speed matters more than size; reported 59.7 tok/s on an RTX 3060. *When:* Running a model on 16GB or 32GB of RAM, or when the task is code and the memory budget is tight.
- **Pre-purchase hardware checklist** — Write down: GPU model and VRAM; RAM size and type (DDR4 or DDR5) and current price; SSD model and speed. Find the Strata performance-table row closest to your setup, then check which operation (prefill or decode) and which context length each number measured before deciding what to buy. *When:* Before buying a GPU or RAM for local inference, to avoid paying for a bottleneck you do not have.

## Hot takes
- The viral 100+ tok/s claim for DeepSeek on a 12GB RTX 5070 was a prefill number presented as generation speed; decode is 4-6 tok/s.
- Running DeepSeek V4.1 Flash locally on a 12GB card with 64GB RAM does not beat renting the API on cost (about 13.5 years of local generation for the price of 2B API output tokens). Local makes sense mainly for privacy.
- The 'you don't need an expensive GPU' premise has shifted: RAM is now about as expensive per GB as VRAM was, so the cost moved to RAM capacity rather than disappearing.
- A 2018 MI50 (about $700 used) matched or beat an RTX 5090 on DeepSeek decode because expert capacity, not GPU speed, sets decode throughput here. Caveat: single warm-cache runs with different settings.
- Strata performance optimizations can trade quality for speed (a routing shortcut was reverted after a drop in agent task success), so re-benchmark tasks, not just tok/s, after each release.
