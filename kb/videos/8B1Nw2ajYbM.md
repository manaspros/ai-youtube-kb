> Quick tour of React 19.2's six new features: Activity for state-preserving hide/show, useEffectEvent, cache signal for aborting renders, performance tracks in Chrome DevTools, partial pre-rendering in react-dom, and an upgraded ESLint plugin.

## Summary

The speaker shows the Activity component as a replacement for conditional rendering so that hidden components keep their state and can pre-fetch data, with effects unmounted and updates deferred while hidden. ## Key ideas
- **Activity replaces conditional rendering for hide/show and keeps state** — Wrapping a panel in Activity with mode="visible"|"hidden" instead of a conditional preserves uncontrolled input text and useState values across close/reopen. Conditional rendering unmounts and loses everything. Hidden content is set to display:none, not removed, and its effects are unmounted and updates are deferred for performance. ([0:00](https://youtu.be/8B1Nw2ajYbM?t=0))
- **Hidden Activity trees can still fetch data for pre-rendering** — Because a hidden Activity renders without running effects, data fetching that starts during render can still happen before the user opens the tab. The speaker shows a slow-load tab that is fetched before click when wrapped in Activity. He notes he had covered Activity in an earlier video when it was experimental. ([1:08](https://youtu.be/8B1Nw2ajYbM?t=68))
- **useEffectEvent solves the stale-value problem inside effects** — When an effect needs the latest counter but must only re-run on URL change, adding the counter to the dependency array restarts the timer on every update, and omitting it captures a stale value. Moving the logic into a useEffectEvent and calling it from the effect lets it read current props and state without being a dependency. The speaker's rule of thumb: use it for logic that is triggered by an effect rather than by a user event. ([1:08](https://youtu.be/8B1Nw2ajYbM?t=68))
- **cache signal lets async work stop when React abandons a render** — Server-side cache() memoizes a function within one render. The new cache signal is an AbortSignal that flips to aborted once React finishes the render, whether it was cancelled (for example, user navigated away or an error) or completed successfully. Pass it into fetch or DB calls so work nobody needs is cancelled. ([2:17](https://youtu.be/8B1Nw2ajYbM?t=137))
- **Performance tracks show React work in Chrome DevTools without React DevTools** — React adds custom tracks to Chrome Performance profiles. The Scheduler track shows work by priority (blocking for user input, transitions inside startTransition). The Components track shows the component tree being rendered or running effects, with labels such as mount and blocked for yielding to work outside React. ([3:30](https://youtu.be/8B1Nw2ajYbM?t=210))
- **react-dom partial pre-rendering and an ESLint plugin upgrade round out the release** — react-dom now supports partial pre-rendering: return the prelude (static shell) to the client, then call resume to render the rest. The speaker expects mainly framework authors to use it. The eslint-plugin-react-hooks update supports flat config and opt-in React Compiler rules, which the speaker recommends enabling so the codebase can use the compiler. ([3:30](https://youtu.be/8B1Nw2ajYbM?t=210))

## Techniques
- **Keep component state across hide/show with Activity** — Replace {open && <Sidebar />} with <Activity mode={open ? "visible" : "hidden"}><Sidebar /></Activity>. The Sidebar component itself needs no changes. Hidden content stays mounted, gets display:none, and keeps useState and uncontrolled input values. *When:* Panels, tabs or sidebars where users expect state to survive closing and reopening, or where you want data fetched before the user navigates to the tab.
- **Read latest state inside an effect with useEffectEvent** — Move the side-effect body that needs current values (for example, logging the counter) into a function wrapped in useEffectEvent, accept the changing trigger value (URL) as an argument, and call that function from useEffect. Leave the effect's dependency array limited to the real trigger, such as the URL. *When:* An effect must re-run only on specific dependencies (for example, a timer started on URL change) but also needs the most recent props or state, and adding those values as dependencies would reset the effect.
- **Cancel wasted server work with cache signal** — In a server-component cache()-wrapped async function, read the signal exposed by the new cache signal API and pass it to fetch or a database client. The signal aborts when React finishes or abandons the render. The speaker does not show the exact call signature. *When:* Server rendering may be cancelled by navigation or errors and expensive async calls (fetch, DB queries) should stop when their result is no longer needed.
- **Profile React in Chrome DevTools using the built-in tracks** — Record a Performance profile in Chrome while exercising the app, then look at the Scheduler track for priority lanes (blocking, transitions) and the Components track for mount, effect and blocked labels. No React DevTools extension needed. *When:* Diagnosing slow renders, transition timing or effect cost in a React 19.2 app.
- **Enable React Compiler lint rules via the updated ESLint plugin** — Use the react-hooks ESLint plugin with flat config and opt into the React Compiler-powered rules. The speaker's advice is to follow these rules so the codebase stays compatible with the compiler. He does not show the config file. *When:* Preparing a React codebase to adopt the React Compiler, or enforcing rules-of-hooks style discipline in a flat-config project.
