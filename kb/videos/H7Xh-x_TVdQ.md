> Walkthrough of Shannon, an open-source AI pentester built on the Claude Agent SDK: Temporal-orchestrated phases, parallel vulnerability agents, and a 2.5-hour, roughly $60 run against OWASP Juice Shop.

## Summary
The creator installs Shannon on a VPS under a non-root user and runs it against OWASP Juice Shop, a deliberately vulnerable app, with the target repo placed inside the Shannon repo directory. Shannon runs through Docker Compose and uses Temporal for durable execution, so a crash or running out of API credits resumes from the last checkpoint rather than restarting. The pipeline has five phases: pre-flight checks, pre-recon static code analysis, Playwright-driven recon of the live app, five parallel vulnerability-analysis agents (injection, XSS, auth, SSRF, authorization) each followed by an exploit agent, and a final report agent. The full run took almost two and a half hours, with retries after the creator ran out of credits. The deliverables directory holds detailed reports, including an auth report claiming 11 critical findings with reproduction steps such as curl commands. The creator says Shannon Pro adds CVSS scoring, CI/CD support, API access and enterprise compliance reporting, but not speed. The run cost about $60 in Sonnet 4.6 API credits, and the video notes that Claude subscriptions cannot be used. The verdict is that Shannon suits startups replacing paid pentests, not indie hackers with tight budgets.

## Techniques
- **Temporal-backed durable agent pipeline** — Run each phase as a Temporal workflow activity so progress is checkpointed. After a crash or a credit top-up, the run restarts from the last checkpoint. Watch progress in the Temporal web UI or the real-time logs (the creator prefers logs because the UI does not always show enough detail). *When:* Long-running agent jobs (hours) where a crash or an external limit should resume rather than restart, such as security scans, large code migrations, or batch evals.
- **Static analysis then live-app recon** — First run a code-analysis pass that maps architecture, entry points and security patterns. Then run a browser agent (Playwright) against the running app to click through functionality, fill forms, capture network requests, cookies and screenshots. Feed both into the vulnerability stage. *When:* When findings must be confirmed against real runtime behaviour, not just code patterns, and the app can run locally.
- **Parallel specialist fan-out with paired exploit agents** — Split the vulnerability search into independent classes (injection, XSS, auth, SSRF, authorization). Each class gets a vulnerability-finding agent, followed by an exploit agent. Run all classes in parallel, then have a report agent combine the output. *When:* When the search space splits into independent categories and total wall-clock time matters more than token cost.
- **Reproduction setup as described in the video** — Clone the Shannon repo. Place the target repository inside the Shannon repo directory. Start the target app locally so the browser agent can reach it. Start Shannon with Docker Compose; the first run pulls images from Docker Hub. Set a Claude API key, since subscriptions do not work. The exact run command is not shown in the transcript, so check the Shannon README. *When:* Reproducing the pentest on a local or VPS test target, such as Juice Shop.

## Hot takes
- The title says 'Powered By Claude Code', but the video itself says Shannon is built on the Anthropic Agent SDK, not on Claude Code. The title is misleading.
- The 'zero false positives' claim is not tested. The creator does not verify any finding against a known ground truth.
- Shannon's runs cannot use a Claude Pro or Max subscription, so cost is the main barrier. The creator says a subscription would have made this much cheaper.
- The claim that later runs are much faster than the first run comes from the creator's research, not from a measured second run.
- Shannon Pro is sold on compliance and integration, not speed, which means the paid tier does not address the main pain point the creator raises.
