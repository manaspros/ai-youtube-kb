## Techniques
- **Install operative.sh web-eval MCP into Cursor** — Get an API key from the operative.sh dashboard (API keys section). Run the installer command from the site in a terminal. It fetches and runs an install script, then deletes the script. Choose Cursor when asked where to install, paste the API key when prompted, and restart Cursor (refresh, or close and reopen, if the tools do not show up). The speaker says the installer edits the MCP config file, which he names mcpconfig.json. The exact installer command is not shown on screen. *When:* When you want Cursor or another MCP client to drive a real browser against a running app without writing Playwright code.
- **Call the web eval agent with url, task and headless** — Ask in plain English, for example 'test the login on the local app'. The agent fills the url (for example http://localhost:3000), the task (step-by-step actions derived from your description) and headless (default false; say 'headless' to run it hidden). Watch the live preview and console/network tabs in the dashboard. *When:* For end-to-end checks of user flows (sign-up, login, logout) on a locally running web app.
- **Save an authenticated session once with setup-browser-state** — Call the setup-browser-state tool, optionally with a URL, and sign in manually in the opened browser. The session is saved, so later web-eval runs do not need to log in again. *When:* When the app under test sits behind authentication and you do not want each run to log in again.
- **Generate test cases to a file, then run them sequentially and write results back** — Ask the coding agent to write test cases for a feature, including edge cases, into a markdown file (the demo used login test cases). Then ask it to run each case with the web eval agent (url localhost:3000, headless on) and mark each as passed or failed in the file. Results appear in the file one case at a time. *When:* For broad coverage of one feature without writing test scripts by hand. Expect it to be slow (about 7 minutes for 10 cases in the demo) and to need a review of the skipped cases.
