## Techniques
- **Adaptive thinking gate** — Let the model decide per task whether to run extended chain-of-thought, instead of forcing it on or off. Measure task completion rate and token cost against always-on CoT on your own tasks before adopting it. Vendor reports about 20% token savings with completion kept. *When:* Agent workloads that mix trivial and hard steps, where always-on reasoning burns tokens. Compare on your own eval set first, not the vendor's internal test.
- **Sensitive-category model routing** — Send a defined class of queries, here cybersecurity, to a different model and keep the default model for the rest. The vendor reports this routing hits under 5% of sessions. *When:* When one product tier needs stricter handling than another. Relevant to strategy routing in a gateway or proxy, pending your own measurements of the routing rate.
- **Persistent file-based memory for long agent runs** — Give the agent a memory directory of files that persist across runs, and measure the gain against a baseline model on a long, stateful task. The reported test is a Slay the Spire run, with 3x the gain over Opus 4.8. *When:* Multi-session or checkpoint/resume agent runs, where the agent must recover context. Test on your own long-running task, since this result comes from a single game.
- **Latent-space scene memory (Mirage)** — Store scene content as 3D latent tokens, initialize the cache from the first frame, read it for each target view, and write new static content back, with no RGB rendering in the loop. *When:* Video world models that need consistent scenes over long camera trajectories and where renderer round trips dominate cost.
- **Interaction-centric tokens for cross-embodiment policies (HumanEgo)** — Record demonstrations with head-mounted egocentric glasses, lift the hand-object interaction into entity-level spatial tokens instead of raw video, and add dense auxiliary losses for object motion, hand pose and contact prediction. *When:* Robot policy learning where robot teleoperation data is expensive and new tasks need quick data collection.
- **Skeleton-free motion transfer (SCAIL 2)** — Concatenate the driving video's latent tokens into the generation sequence instead of extracting a pose skeleton. The paper trains this on paired motion data (MotionPair60K). *When:* Character animation with close multi-person interaction, where skeleton overlap causes limb misattribution.
- **Geometry from a 4D reconstruction model as a video-diffusion condition (LeVar)** — Pull the implicit 3D knowledge out of a pretrained large reconstruction model's latent space and condition video diffusion on it, instead of conditioning on a rendered point cloud. *When:* Camera re-rendering of existing footage where point-cloud rendering breaks on depth errors.
