> A tool roundup for hardening and extending OpenClaw agents: a security skill suite, a deterministic multi-agent workflow runner, a hybrid memory plugin, a network-API browser skill, Cloudflare hosting, a dashboard, and a curated skill list.

## Summary
AI LABS presents seven add-ons for OpenClaw, an open-source agent framework, motivated by security problems Cisco flagged and by cost. The speaker's team installs each one by copying the README's install command, then shows one demo run. The security pick is ClawSec, a suite of audit skills that verifies its own integrity by checksum and re-downloads from the trusted release on mismatch. Antfarm is a multi-agent system of deterministic, YAML-defined workflows with a per-step verifier agent, retries and a Kanban dashboard. MemoryLanceDB Pro adds re-ranked hybrid vector search and session memory on top of OpenClaw's built-in memory, using a Jina embedding model. Unbrowse replaces screenshot-driven browsing with replayed site APIs and browser cookies, which the speaker admits is a security risk. MoltWorker is Cloudflare's experimental official repo for running OpenClaw on Workers, and a community dashboard tracks sessions, cost and cron jobs. The video closes by noting that the ClawHub registry (over 15,000 skills) is polluted, and points to a curated list that cuts it to about 5,400. Substance per tool is thin: most segments show installation and a single happy-path run, and security claims are asserted rather than tested.

## Key ideas
- **OpenClaw's two big problems are security and cost, and third-party integrations make both worse.** — The speaker says Cisco flagged OpenClaw's security problems in detail, and that a week of running it makes the bills add up quickly. The team had already built its workflow on OpenClaw, so it set out to fix the problems rather than switch tools. ([0:00](https://youtu.be/JC53AcoFh-Q?t=0))
- **ClawSec is a skill suite that audits OpenClaw's own installed skills and checks their integrity.** — It was developed by Prompt Security (captioned as a subcompany of 'Sentinel-1'). Its skills include Heartbeat, Soul Guardian and OpenClaw Watchdog. It verifies each file against a checksum, re-downloads from the trusted release if the hash fails, and runs a CI/CD pipeline for continuous checks. ([0:00](https://youtu.be/JC53AcoFh-Q?t=0))
- **The ClawSec Heartbeat polls a feed, checks installed skills against known CVEs, and asks for approval before removal.** — The speaker ran the heartbeat from the OpenClaw chat. The report covered sanity checks and version conflicts, ranked findings by CVE severity, marked which versions were exploitable, and listed actionable fixes. ([1:27](https://youtu.be/JC53AcoFh-Q?t=87))
- **Antfarm runs deterministic, step-by-step multi-agent workflows, each step checked by a dedicated verifier agent.** — Workflows are YAML, which the speaker calls more token-efficient than long Markdown prompts. Each agent starts with a fresh context window, retries automatically, and reports back if retries run out. A dashboard shows the Kanban state of each workflow, and the repo is credited as having 1.9k stars. ([2:52](https://youtu.be/JC53AcoFh-Q?t=172))
- **MemoryLanceDB Pro improves OpenClaw's built-in memory with re-ranking and session memory.** — It is a hybrid vector search layer over LanceDB. Re-ranking resurfaces the most relevant memories rather than only the most recent, and session memory keeps context across conversations. Embeddings come from a Jina model, and the speaker says a free key covers up to 10,000 tokens. ([4:20](https://youtu.be/JC53AcoFh-Q?t=260))
- **Unbrowse gives the agent a browser that works by replaying site APIs rather than driving pixels.** — It reads the network traffic behind a page, rebuilds the endpoints, and reads cookies straight from the user's browser to send authenticated requests. This is why it keeps working across sessions, unlike Playwright-style agents. The speaker concedes that network access is a security risk and says capture and execution code stays on the machine. ([6:47](https://youtu.be/JC53AcoFh-Q?t=407))
- **MoltWorker is Cloudflare's experimental official way to run OpenClaw on Workers.** — It combines sandbox containers and R2 buckets, supports Telegram, Discord and a web UI, and comes with browser-automation skills. The speaker notes a known issue: secrets are visible in process arguments. The model provider can be switched through Cloudflare's AI Gateway without redeploying. ([7:47](https://youtu.be/JC53AcoFh-Q?t=467))
- **The skill ecosystem is polluted, so a curated list is needed before installing anything.** — The speaker cites Cisco for the claim that many ClawHub skills collect data and send it to remote servers. The Awesome OpenClaw Skills repo filters about 15,000 ClawHub skills down to about 5,400 by removing scams, duplicates and malicious skills flagged by several audit tools, then categorizes them. ([10:16](https://youtu.be/JC53AcoFh-Q?t=616))

## Techniques
- **Installing a skill from git when the registry is rate-limited** — When the registry install fails with 'skill not found' because of a rate limit, have the agent clone the skill repo with git and place it in the OpenClaw skills folder under .openclaw. Restart the gateway with `openclaw gateway restart` (captioned as 'open claw gateway restart'). The skill should then appear in the web UI. If it does not register, copy it manually into the skills folder. *When:* Installing community OpenClaw skills when the marketplace registry throttles downloads.
- **Self-verifying skills: checksum check with re-download on mismatch** — Each skill file is hashed and compared against a published checksum on every run. On mismatch, the skill re-downloads the file from the trusted release documented in its repo, and a CI/CD pipeline runs the same checks continuously. *When:* Running third-party agent skills where a tampered file could cause harm.
- **Scheduled security heartbeat over installed skills** — Ask the agent to run the suite's heartbeat. It polls the advisory feed, compares each installed skill version against known CVEs, and proposes removals that need human approval. Its output is a severity-ranked report with fixes. *When:* Periodic audit of an agent's installed skills and plugins for known vulnerabilities.
- **Deterministic multi-agent workflow with verifier and fresh contexts** — Define each workflow as an ordered series of agents in YAML, one per step. Give every agent a fresh context and a guided prompt for its task. After each step a dedicated verifier agent checks the output. Failed steps retry automatically, and if retries run out the run reports back. List workflows with `antfarm workflow list` and watch progress on the local Kanban dashboard. Custom workflows can be generated by asking Claude or the agent to write the YAML. *When:* Multi-step tasks such as a security audit of a project, where ordering must be predictable and errors need to be easy to locate.
- **Re-ranked hybrid memory as an agent memory plugin** — Install the plugin with its install commands, then restart the gateway. It registers once the gateway is restarted. Store a preference by asking the agent to save it, then confirm by inspecting the plugin's data files, which the speaker found in binary form under the .openclaw workspace's plugins folder and extracted with scripts. Embeddings use a Jina model, and a free API key covers up to 10,000 tokens. *When:* Long-running agent setups where the built-in memory retrieves poorly and recent memories crowd out relevant ones.
- **Replaying site APIs with cookies instead of driving a browser visually** — Install the skill with its install command, select OpenClaw as the target agent, and copy the skill into the .openclaw skills folder if the gateway does not register it. The agent sets up its own environment on first use. Afterwards it reads cookies from the user's browser and replays the API endpoints it reconstructed from network traffic. *When:* Research or data fetching from authenticated sites where screenshot-based browser agents are slow or lose their session. Treat it as high-risk because it exposes network and cookie access.
- **Filtering a large skill registry before installing** — Use the curated Awesome OpenClaw Skills list. It filters out scams, duplicates and skills flagged by multiple audit tools, and groups the rest into categories such as Git and GitHub, coding and automation. *When:* Choosing third-party skills from a large unvetted marketplace.
