## Summary
A weekly news roundup from Kai Explains (16:27, 2026-07-02) covering four releases. - **Pager turns a 360-degree panorama into six cube faces so a flat-photo depth model can run on it** — Panoramas break models trained on perspective photos because of polar distortion. Pager projects the sphere onto six cube faces, feeds them as ordinary photos, and gets coherent geometry because adjacent faces share edges. One forward pass yields relative depth, metric depth in meters, surface normals and a sky mask. ([9:25](https://youtu.be/WVC03w3AG6k?t=565))

## Techniques
- **Reproject non-native inputs into the distribution a model was trained on (Pager)** — Convert a 360-degree equirectangular panorama into six cube faces, run a perspective-trained depth/normal model on each face as an ordinary photo, and rely on shared cube edges for coherence. Output one forward pass with depth, metric depth, normals and sky mask. *When:* When a strong model exists for standard images but breaks on a different camera geometry (panoramas, fisheye, LiDAR-style spherical data) and retraining is not an option.
- **Split a streaming avatar into an LLM planner and a joint audio-video diffusion generator (StreamChar)** — The LLM decides the spoken content and the DiT jointly denoises audio and video in streaming chunks, with a sync chunk memory to hold identity across chunks and online rollout distillation to stabilize long generations. Described at the architecture level only; no code or weights are mentioned. *When:* Real-time interactive characters where separate TTS-then-animate pipelines add latency and cannot stay in sync over long sessions.
- **Try Mellum 2 Thinking as a low-active-parameter coding model** — Use the Apache 2.0 Thinking checkpoint from Hugging Face. The model emits reasoning inside think tags before the final answer, so parse or strip those tags downstream. The host gives no serving config, quantization or hardware numbers. *When:* Coding or IDE-agent workloads where per-token compute matters and scientific or math accuracy is not the priority; benchmark it yourself before adopting it.
