- **You can author your own design system instead of relying on Stitch's default, by writing a theme or uploading a design file.** — The design.md must follow a structure; the speaker points to a template in Google's official Stitch skills repo, optimized for Stitch and agents. Agents brainstorming an app can produce a design.md from a style description on top of that template, then paste it into the design.md field of Create new design system. ([1:28](https://youtu.be/b0lwCDNOFUY?t=88))
- **The Redesign feature uses a screenshot as a style and pattern reference instead of copying it.** — It pulls component placement, patterns and design language and applies them to your own site, so the output is original but built on a proven niche layout. A full-page capture (GoFullPage extension suggested) avoids section-by-section screenshots. Images are generated with NanoBanana. ([4:04](https://youtu.be/b0lwCDNOFUY?t=244))
- **You can import a design.md from any website URL, and correct a mismatched style with a rough sketch or wireframe plus an explicit theme.** — Stitch crawls the site and extracts style and typography. The speaker says Stitch often misses the intended style, so references and theme text are the fix. ([4:04](https://youtu.be/b0lwCDNOFUY?t=244))
- **Iterative fixes use Stitch's annotate-and-apply editing on the specific part you dislike, instead of regenerating the whole page.** — Annotate the element, describe the change, click apply. ([5:32](https://youtu.be/b0lwCDNOFUY?t=332))
- **Stitch's skills (Enhance Prompt, Stitch Loop, React component) only work after the Stitch MCP is connected, and a CLAUDE.md can chain them in order with a human approval gate.** — Enhance Prompt rewrites vague prompts into Stitch-style prompts using adjective-based mood keywords. Stitch Loop drives Chrome DevTools in an autonomous build loop with prompt tracking. The React component skill splits the monolithic exported HTML into modular components with validation scripts. - **Exported Stitch output is one large chunked HTML file, which is costly for agents to map to React, so componentize it with a dedicated skill.** — The speaker's CLAUDE.md order is: enhance the prompt, pause for permission, load Stitch Loop and create the project through MCP, send the design system and then the design, then use the React component skill to implement a component structure. ## Techniques
- **design.md-first design system** — Have Claude draft a design.md that follows Google's Stitch design.md template (from the official Stitch skills repo), describing the target style. Paste it into the design.md field under Create new design system, click Save design to get the visual, then ask Stitch to implement UI using that system as the base. Reuse the same system for every page. *When:* Multi-page sites that must share one look, or when the style was brainstormed with another agent and needs to carry over.
- **Extract design.md from an existing Stitch project** — Install Google's design.md skill from the Stitch skills repo and run it against the project; it converts the project into a design.md in the Stitch template. *When:* You have a design in Stitch already and want to reuse its style elsewhere or as a starting point for a new design system.
- **Screenshot as style reference (Redesign)** — Capture the whole reference page in one image (the speaker uses the GoFullPage extension), upload it to Stitch's Redesign feature, and let Stitch apply its patterns, component placement and design language to your own content. *When:* You want an original site built on a layout pattern that already works for the niche, not a clone.
- **Import style from a URL** — In Stitch's design systems area, supply the site's link; Stitch crawls it and writes a design.md capturing style and typography. *When:* You want to match a site's look without a screenshot.
- **Sketch plus theme to correct drift** — When generated output misses the intended style, upload a rough sketch or wireframe and state the theme explicitly in the prompt so the output matches both. *When:* The default generation keeps producing a style you do not want.
- **Annotate-and-apply targeted edits** — Use Stitch's annotation tool on the part you want changed, write the change, and click apply. *When:* A single section or component needs adjustment after the page is generated.
- **CLAUDE.md pipeline for Stitch skills** — List the order in CLAUDE.md: (1) load the Enhance Prompt skill and show the enhanced prompt, (2) wait for user approval, (3) load Stitch Loop, create the project through the Stitch MCP, and send the enhanced prompt (design system first, then design), (4) load the React component skill to componentize the output, and (5) whenever Stitch MCP is used, load the shadcn skill to convert components. The speaker says the stages run in that order once the prompt is approved. *When:* You want a one-shot landing page or app build with a human checkpoint before the costly build step.
- **Convert a Stitch project to shadcn/ui** — Give Claude the Stitch project name, have it fetch the project, load the shadcn UI skill, and use shadcn MCP calls with the registries you listed (for example Glassmorphism and Motion Primitives) to implement the app. *When:* You already designed in Stitch and want an interactive, animated app rather than static markup.
