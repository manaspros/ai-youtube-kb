> Walkthrough of connecting the open-source apple-mcp server to Cursor so an agent can read and act on Apple Contacts, Notes, Messages and Reminders; mostly setup steps, with a useful note on restructuring a tool's navigation.

## Summary
The presenter installs a GitHub project called apple-mcp, an MCP server that exposes native Apple apps (Contacts, Notes, Messages, Calendar, Reminders and others) to an AI agent, and wires it into Cursor's MCP settings as a command-type server. Working setup needs the full absolute path to the server's index.ts, a Cursor restart after config changes, and Cursor's Composer set to agent mode. The demo sends a greeting message and fetches reminders from inside Cursor, with macOS permission prompts appearing for each Apple app. Because the upstream README listed some features as to-do, the presenter asked the agent to implement them by copying the structure of the existing utility modules. The Notes tool first returned every note unsorted, which the presenter fixed by restructuring it into a hierarchy (list folders, open a folder, list notes, read one) while keeping search. The video is a single-user, anecdotal demo with no evaluation, benchmarks or discussion of the security implications of giving an agent message-sending access.

## Techniques
- **Register a local MCP server in Cursor** — Open Cursor Settings, go to Features, then the MCP Servers section, and click add new. Give it any nickname (the presenter uses 'Apple MCP'), set Type to 'command', and paste the run command. Wait for the status to turn from red to green once tools are detected. Restart Cursor after any change to the entry. The exact runtime prefix in the command is not clearly audible in the transcript; the presenter says to enter the runtime followed by the full path to index.ts. *When:* Wiring any local stdio MCP server into Cursor, especially one whose README gives a relative path that will not resolve from Cursor's working directory.
- **Get the absolute entry path for an MCP server** — Clone the repo, run the local development commands from its README up to bun install (the last command is left out because Cursor runs it), move into the project directory, and run realpath index.ts. Copy the full path it prints into the Cursor command entry. *When:* Cursor cannot resolve a relative path to a local MCP server, or the server works from the terminal but not from the IDE.
- **Use agent mode to call MCP tools** — Switch Cursor's Composer from chat to agent mode before prompting. The presenter reports that MCP tools do not run otherwise. Prompts such as 'send a greeting message to my friend' then use the contacts lookup and then the messages send tool in sequence. *When:* Testing an MCP server in Cursor, or when tools appear in the list but never run.
- **Extend an MCP server by having the agent copy existing modules** — Point the agent at the repo's README, ask it to read the features list and implement the items marked as to-do, and tell it to follow the structure of the completed utility files (contacts, messages, notes). Review the output afterward; the presenter then re-prompted for fixes. *When:* An MCP server has a clear pattern across its tool modules and a list of unfinished features, and you want the agent to fill the gaps in the same style.
- **Restructure a search-everything tool into hierarchical navigation** — Replace a single search-all tool with a sequence of narrower tools: list folders, open one folder and list its items, then read one item. Keep the search tool as a separate entry point. The presenter asked for this in a prompt and then tested each step (folders, notes in one folder, note contents). *When:* An agent tool returns a flat, unsorted list of many items (notes, files, messages). Narrowing the tool surface makes results easier for the model to navigate.

## Hot takes
- The title ('insane integration', 'crazier day by day') is hype. The video is one repo walkthrough with no evaluation and caps at quality 2.
- The video shows an agent sending a text message after a single one-time macOS permission grant, and does not discuss the risk of that access. This is the part most relevant to our security-guardrails work.
- Structure beat model choice: the presenter's fix for the unsorted Notes output was restructuring the tool's navigation, not switching models or changing the prompt alone.
