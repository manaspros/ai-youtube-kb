## Summary
Better Stack presents ten CSS features it says are worth knowing for 2026. The first group covers shapes: corner shapes (bevel, notch, scoop, squircle) and the shape() function, which the speaker describes as a more capable path() that accepts CSS units and math functions and works with clip-path and offset-path. Next are native UI features: appearance: base-select makes the select picker and its options stylable, and scroll markers plus scroll-button pseudo-elements build a carousel with no JavaScript. Scroll-state container queries style elements by whether a container is stuck, snapped or scrollable, which the speaker frames as replacing scroll listeners and timeouts. Smaller items are the stretch keyword (sizes include margins, unlike 100%), textbox trimming to cap height or x-height for aligning text with images, and sibling-index() for staggered widths and delays. The last group is functions: if() for inline media, style or supports conditionals, and author-defined CSS custom functions with parameters, local variables and a return value. The video is a feature tour with on-screen demos; the transcript contains no code, and browser support and fallbacks are never discussed.

## Key ideas
- **Corner shapes go beyond border-radius: bevel, notch, scoop and squircle, with different options per corner, without SVG or path clipping.** — Round is the default radius; bevel cuts a straight diagonal, notch an inward rectangular cut, scoop an inward curve. The speaker calls squircle his favourite. ([0:00](https://youtu.be/svqu6FDiMAs?t=0))
- **shape() is presented as path() on steroids for clip-path.** — Unlike path(), which is limited to pixels, shape() takes percentages, rem, and CSS math such as calc, max and abs. Combined with offset-path it can drive animations along custom outlines. ([0:56](https://youtu.be/svqu6FDiMAs?t=56))
- **The select element can finally be styled natively via appearance: base-select.** — The picker, the picker icon (animatable on open/close), the open state and individual options (including checked state and a custom checkmark) are all styleable, with no JavaScript replacement. ([0:56](https://youtu.be/svqu6FDiMAs?t=56))
- **Scroll markers and scroll-button pseudo-elements build a JS-free carousel.** — Set the scroll-marker group to after on the scroll container, style each item's marker including its active-target state, then lay the markers out with flex and a gap. scroll-button adds prev/next buttons to a scroll container. ([2:11](https://youtu.be/svqu6FDiMAs?t=131))
- **Scroll-state container queries replace scroll event handlers for stuck, snapped and scrollable states.** — The container needs container-type set to scroll state (optionally named). Stuck styles a sticky header once it sticks, snapped styles carousel items that are the current snap target, and scrollable checks whether the container can scroll in a direction (used to show a back-to-top button). ([3:24](https://youtu.be/svqu6FDiMAs?t=204))
- **stretch sizes an element to its margin box, which 100% does not do.** — With a 20px margin on an inner box, width and height of 100% overflow or misplace it, while stretch fills the container including the margin, regardless of box-sizing. ([4:35](https://youtu.be/svqu6FDiMAs?t=275))
- **The textbox property trims the whitespace above and below text to meaningful glyph boundaries.** — Trim-start, trim-end or trim-both, with top edges text or cap or x and bottom edges text or alphabetic. Useful for aligning text tops with an image. The speaker also uses a text-box-edge variant that trims only the top. ([4:35](https://youtu.be/svqu6FDiMAs?t=275))
- **sibling-index() returns an element's position among its siblings, enabling CSS-only staggering.** — Multiplying it by 50px gives widths of 50, 100, 150 and so on for six items; multiplying it by a delay gives staggered animation delays with no JavaScript. ([5:55](https://youtu.be/svqu6FDiMAs?t=355))
- **if() adds inline conditionals to any property, keyed on media, style or supports queries.** — The first true condition wins and an optional fallback applies if none match. Examples: theme colours driven by a style-queried variable set by a button, and flex-direction switching to column below 300px width. ([7:02](https://youtu.be/svqu6FDiMAs?t=422))
- **CSS custom functions take parameters, local variables and return a value.** — Example alpha() takes a colour and a transparency and computes an OKLCH value. Example narrow-wide(narrow, wide) returns one of two values based on whether the container is under 300px, used for flex direction and font size in one place. ([8:06](https://youtu.be/svqu6FDiMAs?t=486))

## Techniques
- **JS-free carousel with scroll markers and scroll buttons** — On the scroll container set the scroll-marker group to after. Style each item's ::scroll-marker, including the state for the active target. Center the markers with flex and add a gap. Add scroll-button pseudo-elements for previous and next controls. The speaker demos this with a carousel and no scripts. *When:* Carousels, sliders and image galleries that currently rely on click handlers and index state in JavaScript.
- **Scroll-state container queries instead of scroll listeners** — Set the container's container-type to scroll state, optionally with a container name. Then write queries for the stuck state (sticky header), the snapped state (carousel item at the snap point, restyled with opacity and scale 1), or the scrollable state in a direction (show a back-to-top button only when it can scroll up). *When:* Sticky header styling, scroll-linked reveals, snap-aware carousel animation, and showing scroll-to-top controls.
- **Native select styling with appearance: base-select** — Set appearance to base-select on the select element. Style the picker, the picker icon (animate it on the open and closed states), the open state (for example removing the bottom radius so it joins the options), each option by checked state, and a custom checkmark. *When:* Custom dropdowns that need to look native-consistent without a JavaScript widget library.
- **CSS-only staggering with sibling-index()** — Use sibling-index() as a numeric value in a property, for example width as sibling-index() times 50px, or animation-delay as sibling-index() times a delay unit. No JavaScript or per-item classes needed. *When:* Staggered entrance animations, graduated bars or widths, and any list where each item's position drives a value.
- **Trimming text whitespace for alignment** — Apply the textbox property with trim-start, trim-end or trim-both. For the top edge, use cap to trim to capital height or x to trim to x-height; the default is text. For the bottom edge, use alphabetic to trim to the baseline of most characters, or keep text. The speaker also mentions a text-box-edge variant that trims only the top. *When:* Aligning the top of a heading with an image or another block, where the default line-height whitespace causes visual misalignment.
- **Inline conditionals with if()** — Use if() as a property value with media, style or supports conditions, and an optional fallback as the last argument. The first true condition sets the value. Examples: theme colours keyed on a style-queried variable that a button sets, and a flex-direction that becomes column below 300px. *When:* Replacing pairs of separate media or style query blocks that set the same property, and theme switching with one custom property.
- **Reusable logic with CSS custom functions** — Define a named function with parameters, declare local variables, run logic, and return a value. Examples in the video: alpha(colour, transparency) returns an OKLCH colour, and narrow-wide(narrow, wide) returns one of two values depending on whether the container is narrower than 300px. *When:* Repeated colour calculations or repeated responsive value switches that would otherwise need separate media queries at each use site.
- **Using stretch for full box-model fill** — Set width and height to stretch instead of 100% when the element has margins that should be included in the fill. The speaker says stretch resizes the element including its margin box, regardless of box-sizing. *When:* Elements with margins inside a container that need to fill it exactly, where 100% causes overflow or misplacement.
- **Shapes with shape() on clip-path** — Pass shape() to clip-path with a path-like outline built from line and arc commands, including horizontal and vertical lines. Use percentages, rem units and calc/max/abs for coordinates. Pair with offset-path to animate an element along the outline. *When:* Non-rectangular clipping, star or custom outline shapes, and motion along a custom path without SVG.
