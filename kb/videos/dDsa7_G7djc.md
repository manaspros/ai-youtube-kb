## Techniques
- **Rewind to a checkpoint in Claude Code** — Use the /rewind slash command, or press Escape twice. Pick the point to restore to. Claude Code restores to the state before that prompt and forks the conversation from there. Checkpoints are automatic, so no manual git commit is needed. *When:* When a prompt broke something and you want to retry from before it, without committing each step to git.
- **Search prompt history with Ctrl+R** — In the Claude Code terminal, press Ctrl+R and type a word. Matching previous prompts appear, and you can reuse one. *When:* When you want to find and re-run an earlier prompt in a long session.
- **Use the VS Code extension with editor context** — Open the Claude Code VS Code extension. Select code or open a file, then ask for a change. It sees the selection and the open file. Pick a mode (ask before edits, auto-edit, plan) and approve the diff from the inline or bottom approve buttons. *When:* When you want a Copilot or Cursor-style chat tied to the file you are editing, with the CLI's slash commands and permissions.
- **Compare models on one prompt in the same harness** — Use one harness (the presenter used OpenCode) and one starting repo. Give each model the same single prompt, then count the follow-up fixes needed before the app works and check persistence by refreshing. *When:* When you want a quick, practical comparison of coding models on a full-stack task. Note it is a single run per model, so it is weak evidence.
- **Enable context editing and the memory tool in the Claude API** — The video describes these features but does not show config. Context editing clears stale tool calls and results near the token limit. The memory tool is a file-based directory the model can create, read, update and delete on your infrastructure. *When:* For long-running agents that hit context limits, or that need state to persist across sessions without keeping everything in the window.

## Hot takes
- The one-prompt, one-run model comparison is anecdotal, and the presenter says himself that the models are getting hard to tell apart on simple tasks.
- The 30-hour claim and the 'most aligned' claim are vendor-reported, and the presenter repeats them without independent checks. He also notes the alignment gain may come with lower prompt-injection resistance, and says an injection demo is likely soon.
- Praise for Anthropic including other providers' models in its benchmark tables is a useful point about how vendors present comparisons.
- The Imagine with Claude demo is a generative-UI research preview with no shipped product behind it, so the presenter treats it as a glimpse of the future.
