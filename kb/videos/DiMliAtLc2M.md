## Techniques
- **Character-consistent generation from one reference image** — Launch PicLumen, sign in with Google, open the Create tab, pick a model, upload a reference, choose Character Reference, leave strength at the default 0.5, enter a prompt, keep the default aspect ratio, set the count (max 4), and click Generate. *When:* When you need several images of the same person or character in new scenes.
- **Style-consistent generation** — Same flow as character generation, but pick Style Reference instead of Character Reference. *When:* When you want a consistent visual style across images rather than the same character.
- **Region inpainting** — Choose the brush tool, paint over the area to change, type the change in the prompt box (the demo colors a horse white), and generate. *When:* When a generated image is mostly right and only one object needs changing.
- **Building a Flux prompt with the Hugging Face prompt generator** — On huggingface.com, enter a basic idea (the demo uses an astronaut on the moon wearing a cowboy hat), choose an art form (Photography) and a photo type, pick the model that writes the prompt, click Generate, copy the result, and paste it into PicLumen's Flux model. *When:* When short prompts give weak results from Flux and you want a longer, more specific one.
