## Summary
A Kai Explains weekly news roundup covering about ten releases from late June 2026. The headline items are ByteDance's Seedance 2.5 video model (previewed, not shipped, claims 30-second single-pass generation and up to 50 reference inputs) and Sakana's Fugu, a paid multi-agent orchestration API that learns which frontier models to combine per task. It also covers Ant Group's open Ling 2.6 (instruct) and Ring 2.6 (reasoning) trillion-parameter MoE models, ByteDance's Seed 2.1 family, an open image model family (Boogoo, name as transcribed), the 4.63M-parameter Inflect Nano TTS, Adobe Research's Loose Control Video, the bidirectional Unitemp video model, NVIDIA's BioNeMo Agent Toolkit, and Krea 2 open-weight image model. The speaker repeatedly flags that benchmarks are self-reported and not independently verified, and warns that Krea 2 uses a custom community license rather than Apache 2.0. ## Techniques
- **Documented skill specs for domain tools (BioNeMo skills)** — For each callable capability, write a spec with purpose, required inputs, optional parameters, expected output artifacts and failure modes, then expose it to the agent (the toolkit uses MCP). The agent discovers the right tool and interprets results from the spec rather than from trial and error. *When:* When a general agent must reliably call specialized tools with correct inputs and parsing and you want to avoid hand-holding each step. Relevant to skill libraries such as SkillForge.
- **Single-endpoint learned model assembly (Sakana Fugu)** — Send one OpenAI-compatible request. A learned orchestrator selects and coordinates several models per task, replacing hand-written role assignment, fallback and key management. Opt specific providers out for compliance. *When:* When a task spans several frontier providers and hand-written routing is the maintenance burden. The talk describes this as a paid hosted service and gives no independent benchmark.
- **Sparse 3D box blocking for object motion (Loose Control Video)** — Draw a few oriented 3D boxes marking the object's start, path and rotation. The model infers motion, occlusion and interactions. Refine one object's trajectory locally without regenerating the scene. *When:* When you need director-style control of object motion in generated video and dense depth, flow or point-track inputs are too costly to produce.
- **Bidirectional generation for seamless loops (Unitemp)** — Use one model that can extend forward from a start frame, backward from an end frame, or bridge two frames. For a loop, make the first and last frames identical. *When:* When you need seamless loops or transitions between two known states and do not want separate per-direction models.
- **Reasoning effort toggle per task (Ring 2.6)** — Select high or xhigh thinking mode per request to trade compute for quality on each task. *When:* When one model serves both cheap and hard requests and you want to set compute per call.
- **Pick the Krea 2 checkpoint by use (RAW vs Turbo)** — Fine-tune or train LoRAs on RAW, the mid-training base checkpoint, which is not recommended for direct inference. Use Turbo, the distilled post-trained checkpoint, for roughly 2-second inference with style references and mood boards. *When:* Use RAW when you need custom styles or LoRAs and Turbo when you need fast generation. Check the license before commercial use.

## Hot takes
- Nearly every benchmark in the roundup is vendor-reported. The speaker says so for Seedance 2.5, Ling/Ring 2.6, Seed 2.1, Boogoo, BioNeMo, Loose Control Video and Unitemp.
- Seedance 2.5 is only a keynote preview: enterprise beta, with public access targeted for early July, so its claims are untested.
- Krea 2 is not Apache 2.0 despite the open-weight framing: a custom community license requires an enterprise license above 50 seats.
- Boogoo's arena leaderboard was built by its own team, so the ranking involves self-evaluation.
- Fugu is a paid closed API, not open source, despite being covered alongside open-weight releases.
- The intro says the 'Krea 2' model is '$12 billion per parameter', which is a misspeak for 12B parameters.
