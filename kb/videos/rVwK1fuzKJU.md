## Key ideas
- **Mistral Leanstral 1.5 (Lean 4 formal reasoning) reports 100% on miniF2F and 587/672 on PutnamBench, with test-time compute scaling reported as steady from 25K to 4M tokens per attempt.** — Speaker says Leanstral 1.5 is 119B total / 6B active, trained in three stages (formal math/code mid-training, SFT, RL with a custom CISPO algorithm) across a multi-turn prover env and a code-agent env with the Lean language server. Claimed cost about $4 per solved problem versus $300+ for SeedProver 1.5 high setting. Apache 2.0 weights on Hugging Face plus a free API via Mistral Vibe. ([0:00](https://youtu.be/rVwK1fuzKJU?t=0))
- **Leanstral was also run on real Rust repos: the pipeline generated correctness properties and tried to prove them, flagging 47 violated properties across 57 repos, 11 of which were genuine bugs and 5 previously unreported.** — Example given: an integer overflow in a sine function of a zigzag decoding library that would crash in debug builds and silently corrupt data in release builds. ([3:27](https://youtu.be/rVwK1fuzKJU?t=207))
- **Tencent HY3 official release: 295B total / 21B active MoE, 256K context, three reasoning modes (no-think, low, high) selectable per request.** — Speaker reports 74.4% on SWE-Bench Verified, behind Claude Opus 4.6 (80.8%) and GPT-5.4 (78.6%) as cited in the video. Production numbers from the preview in CodeBuddy and WorkBuddy: TTFT down 54%, end-to-end latency down 47%, success rate over 99%. Tencent Cloud pricing is 1 yuan/M input and 4 yuan/M output tokens. ([6:55](https://youtu.be/rVwK1fuzKJU?t=415))
- **Agents A1 (InternScience) is a 35B MoE aimed at long-horizon agent tasks. Its training uses a domain-grounded knowledge-action graph to turn agent traces into training targets, followed by multi-teacher on-policy distillation.** — Reported SOTA on Seal-0 (56.36), Frontier Science Research (40.0) and IFBench (80.61). BrowseComp 75.51 is claimed as best among ~35B-class models. Serves via vLLM or SGLang with a 256K context. ([9:40](https://youtu.be/rVwK1fuzKJU?t=580))
- **CeFi Image is a text-to-image model that splits denoising into a semantic stream and a texture stream, with the semantic stream running a small time-step offset ahead.** — Speaker explains standard diffusion denoises structure and texture jointly. Released in 1B, 2B and 5B sizes. The 5B model was trained on 125,000 A800 GPU-hours. The 5B needs roughly 10-16 GB VRAM depending on quantization, so the smaller sizes are described as consumer-GPU runnable. ([11:51](https://youtu.be/rVwK1fuzKJU?t=711))
- **Depth Anything 3 (ByteDance Seed) predicts spatially consistent geometry from any number of views, with or without known poses, using a plain DINOv2 encoder and a single depth-ray target.** — Claims +35.7% camera-pose accuracy and +23.6% geometric accuracy over VGGT on a new visual-geometry benchmark. Accepted as an ICLR 2026 oral. Community integrations for Blender, ComfyUI and ROS2 are mentioned. Trained only on public academic datasets. ([14:33](https://youtu.be/rVwK1fuzKJU?t=873))
- **GenRecon (TU Munich with ETH Zurich) reconstructs a full room from 8 photos by treating reconstruction as conditional 3D generation, with Trellis.2 scaled to scene level and PBR materials on output.** — The scene is split into overlapping 3D chunks that are generated jointly in a shared latent space. Claims +16% geometric accuracy over baselines. Code and checkpoints released on GitHub on June 29. ([17:01](https://youtu.be/rVwK1fuzKJU?t=1021))

## Techniques
- **Test-time compute scaling for formal provers** — Raise the per-attempt token budget (reported points: 25K, 50K, 200K, 1M, 4M tokens) and measure solved-problem count. Leanstral 1.5 is reported to climb steadily (44 -> 244 -> 493 -> 587 Putnam problems). *When:* When evaluating whether a reasoning model benefits from more inference budget, and for planning cost per solved item instead of per attempt.
- **Property-generation plus formal proof as a bug finder** — The model generates correctness properties from Rust source, attempts formal proofs in Lean, and reports violated properties. The reported 47 violations yielded 11 real bugs. *When:* As a verification layer over real repos to catch overflow and edge cases that tests and fuzzing usually miss.
- **Semantic-first two-stream diffusion** — Run a semantic stream for layout and composition and a texture stream for detail, with the semantic stream denoising a small time-step offset ahead so the texture stream has a structural anchor. *When:* For image generation pipelines where structure and texture fight each other during denoising.

## Hot takes
- Leanstral's cost comparison (about $4 vs $300+ per problem) is a self-reported figure with an estimate behind it, and the speaker repeats it without checking.
- Speaker calls HY3's SWE-Bench Verified score 'genuinely competitive' while also noting it trails the closed models cited; the comparison uses model numbers from the video, not independent runs.
- Speaker says 'the awesome thing is' about each release. Most items are vendor-reported benchmarks with links to project pages, not hands-on tests.
- Consumer-GPU claims are hedged: the speaker says a 119B model is for server hardware, and HY3 is not single-consumer-card runnable.
