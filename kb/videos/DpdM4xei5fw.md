## Techniques
- **Install an MCP UI server into the IDE** — Sign up at the provider's dashboard (21st.dev or Magic UI), open the API docs and keys section, copy the key, and paste it into the install command or MCP config for your IDE. The video shows the key being pasted into the install command; it does not show the exact config file, JSON keys or command text. *When:* When you want an agent in Cursor, Windsurf or VS Code to call the component builder, logo search or inspiration tools.
- **Prompt for a self-contained component, then let the IDE agent place it** — Write one prompt that names the component type, visual details (dark theme, effects), and asks for the section to be built as a component and inserted into the landing page. The agent calls the component builder tool, checks the project structure, then writes the TypeScript file. *When:* For one-off landing page sections that do not need a specific design system.
- **Use logo search to fill in brand or icon assets** — Ask the agent to add logos for named services. It calls the logo search tool, receives SVG or JSX, and writes it into the target component. *When:* When a feature needs logos or icons and you want to avoid searching for and downloading them by hand.
- **Install a catalog component by copying the command** — On 21st.dev, search for a component (global search also covers other UI libraries and previews them). Copy the install command, paste it into the IDE agent prompt, say it is a UI component, and name the file or folder where it should go. *When:* When you want a polished UI element from a library and do not want to pay for generations or depend on generated markup.
