## Techniques
- **Tier-based model selection by VRAM or unified memory** — Check the GPU's memory (or a Mac's or Spark's unified memory). Map it to a tier (4-8, 8-24, 24-96, 96-192, 192-384 GB). Pick the largest model that fits with headroom left for the context window. Picks named: NanBeige 4.2 (4-8 GB), Bonsai (8-24 GB), Qwen 3.6 27B at full precision (24-96 GB), Laguna S2.1 (96-192 GB), Motif 3 (192-384 GB). *When:* Choosing a local model for a given machine before benchmarking candidates.
- **Looped transformer for small models** — Reuse the same layers several times in the forward pass instead of adding more layers. This adds compute, not stored weights. Only the NanBeige 4.2 release is named; no implementation detail is given. *When:* Memory-constrained devices (about 2 GB) where a 3B model must punch above its size on agent, coding or reasoning tasks.
- **Ternary retraining instead of post-training quantization** — Retrain every weight to one of three values (-1, 0, +1), so the whole network is under 2 bits per weight with no full-precision layers. Bonsai is a retrain of Qwen 3.6 27B, not a quantization of its weights afterward. *When:* Fitting a large model into 4-8 GB or onto a phone, where a normal 4-bit build of the same model does not fit. Validate quality on your own evals, since the speaker's comparison is unverified.
- **Fine-tune for shorter reasoning traces (Thinking Cap)** — Apply the Thinking Cap fine-tune on top of Qwen 3.6 27B. Per the speaker, answer quality stays at about the same score while reasoning tokens drop by about half on average. Measure time-to-answer on your own prompts. *When:* Local reasoning models where waiting on thinking tokens is the bottleneck, not raw quality.
- **Serving sparse MoE models locally** — Laguna S2.1 and Motif 3 both run from Hugging Face weights. The speaker says vLLM, SGLang and Ollama run Laguna out of the box, and that NVIDIA tuned Laguna for a single DGX Spark. Only 8B (Laguna) or about 13B (Motif 3) parameters are active per token, which keeps throughput usable. *When:* Hosting a 100B+ parameter open-weight model on a workstation or two-box setup where a dense model of the same total size would be too slow.
- **Local quickstart with Ollama or LM Studio** — Ollama: install it, then run it with the model name (the speaker says 'ollama run' and the model name; the exact tag is not shown). LM Studio: same idea with a GUI and a download button. Models come from Hugging Face. *When:* A first local setup. The video gives no exact model tags, so look up the tag for the chosen model before running.
