> Kai Explains on where AI reverse engineering works: it succeeds when an automated answer key (byte-exact compile match, a test or a crash) grades each attempt, and the headline numbers hide that.

## Summary
The video argues that AI is good at reverse engineering only where a deterministic grader exists to tell the model after each attempt whether it is right. It walks through a decompilation loop (write C, compile with the original toolchain, byte-compare with objdiff, retry up to 12 times) and a Sonnet run that matched 74% of 60 functions from two retro games. It contrasts the Super Smash Bros. Melee decompilation, where years of build-matching work came first, with a Modern Warfare 2 port that dropped the byte-exact reference, produced about 7,000 commits and 34% decompiled functions, but ran almost nothing. It reads OpenAI's reported 99.2% on SREBench as a pass@4 figure (88% on the first attempt), and notes the same model scored roughly 30 to 34% in independent or researcher runs versus 55.9% in OpenAI's own table. It also reframes the cost of a Claude Max user's audit (about $85k at API prices against a $200 subscription, roughly 426x) as a pricing effect as much as a capability result. The last segment applies the same oracle idea to security: a crash is the answer key, and DepthFirst reportedly found 21 FFmpeg vulnerabilities for about $1,000 of compute. The transcript ends near 9:53 while the video runs 10:29, so the last half-minute is missing.

## Key ideas
- **The determining factor is an automated grader: every AI attempt is checked by a script that says right or wrong, and that check is the real capability.** — Reverse engineering with AI works as a search loop because the compiler and byte comparison act as an answer key. The model is cheap and fast at searching but does not understand the code deeply; where no answer key exists, progress stalls. ([5:08](https://youtu.be/hl6VOfzky5E?t=308))
- **OpenAI's 99.2% on SREBench is a within-four-attempts number; first-attempt accuracy was 88%.** — SREBench has 19 researcher-written programs (about 17,000 lines each, 44 anti-analysis techniques) split into roughly 1,572 script-graded tasks. The speaker stresses the attempt budget changes the story. ([2:37](https://youtu.be/hl6VOfzky5E?t=157))
- **Same model, same benchmark, very different scores: budgets, harnesses and grading rules move results by about 25 points.** — Researchers reported GPT-5.6 Sol at 31.5%, Vals at about 30.5% and Claude Opus at about 33.6%. OpenAI's own table lists Sol at 55.9%. The speaker argues the surrounding system matters as much as the model. ([3:57](https://youtu.be/hl6VOfzky5E?t=237))
- **Matching the original compiler and build setup was the six-year prerequisite for Melee's decompilation, and it is what made AI help possible.** — The community spent years reconstructing exact compiler flags and the build system so every decompiled function could be checked against the GameCube disc byte for byte. AI then did the last guessing stretch on top of that infrastructure. ([6:21](https://youtu.be/hl6VOfzky5E?t=381))
- **Dropping the byte-exact reference for a port removes the answer key, and agents then produce code that compiles but does not run.** — The Modern Warfare 2 effort targeted 64-bit, Linux and macOS, so output could not match the original bytes. Four agents made about 7,000 commits over roughly four weeks and decompiled 34% of functions, yet the game did not run because small interface bugs went undetected. The author then said he was switching to byte-exact work. ([8:32](https://youtu.be/hl6VOfzky5E?t=512))
- **The real cost of the agent work depends on the billing model: API-equivalent cost was about 426x the subscription price.** — The audit counted about 235 billion tokens, 89% of them cache reads, which comes to $85,207 at API prices against a $200 per month Claude Max plan. The speaker argues that part of the 'capability' story is really the pricing of flat-rate plans. ([8:32](https://youtu.be/hl6VOfzky5E?t=512))
- **Security is the same loop with a crash as the answer key, and the cost per bug is low.** — DepthFirst reportedly pointed agents at FFmpeg (about 1.5 million lines of C), found 21 previously unknown vulnerabilities for about $1,000 of compute (roughly $48 per bug), and the oldest dated to 2003. ([9:53](https://youtu.be/hl6VOfzky5E?t=593))
- **Headline results like 'AI rebuilt Photoshop' or 'AI decompiled a game' need the grading and attempt details before they are interpreted.** — The speaker separates verified results (byte-matched functions, crashes that reproduce) from demo-style claims and from projects that compile but do not run. Photocraft, a Rust rebuild of Photoshop with 28,000 GitHub stars, is cited but not evaluated. ([1:16](https://youtu.be/hl6VOfzky5E?t=76))

## Techniques
- **Build the oracle before the loop** — Before letting an agent iterate, write or obtain a deterministic check (reference output, byte-compare, test suite, or crash/sanitizer signal) that returns pass/fail with specifics. Feed the failure detail back on every attempt, and cap retries (the decompilation loop uses up to 12 attempts per function). *When:* Any task where correctness can be checked mechanically, such as decompilation, codegen to a known output, or test-driven fixes. Skip the loop when there is no grader.
- **Compile-and-byte-compare decompilation loop** — Use Ghidra to get a disassembly skeleton. Have the model propose C for one function. Compile it with the exact original compiler and flags. Compare the bytes to the original with objdiff. Accept on an exact match, otherwise retry with the diff. *When:* Reverse engineering a binary where you own or have rights to a reference build and a matching toolchain can be reconstructed.
- **Reconstruct the toolchain first** — Spend the early effort pinning the exact compiler, flags and build system so that a match is meaningful. Only after that, automate function-level guessing. *When:* Any project where agent output will be checked against a binary or artifact that the build must reproduce exactly.
- **Keep the reference when changing the target** — If the goal is a port or a modified build, keep some automated check at the unit or interface level. An end-to-end run alone can hide many small faults that each look fine in isolation. *When:* Porting or refactoring at scale with several agents writing in parallel, where thousands of commits can each look correct.
- **Report pass@1 and pass@k with the budget** — When comparing agent or model benchmark results, state the attempt budget (first try versus best of k), the harness, and the grader. Rerun independently when a vendor table differs from third-party numbers. *When:* Reading or publishing any agent benchmark, or choosing a model based on a headline number.
- **Track API-equivalent cost next to subscription spend** — Estimate the token audit at API prices, separating cache reads from fresh input and output tokens, and compare that to the actual plan cost. The speaker's example shows cache reads dominate the bill. *When:* Judging whether a long agent run is economical, or deciding between a flat-rate plan and per-token API billing.

## Hot takes
- The 99.2% headline is a within-four-attempts figure; the first-attempt number is 88%, and the claim that the problem is nearly solved is not like-for-like.
- The 25-point gap between researcher and OpenAI tables shows the harness, budget and grader can matter more than the model, so single benchmark numbers are weak evidence.
- Much of the 426x 'cost' gap is API versus subscription pricing, not compute, so the 'capability breakthrough' is partly a pricing decision.
- Reverse engineering with AI is a search over an answer key; the community's years of build-matching infrastructure did most of the groundwork, not the model.
- Ported or modified targets that cannot be byte-matched lose the answer key, and thousands of agent commits can still yield a non-running program.
- The speaker reports that a viral video told viewers to sell software stocks and disputes the conclusion from its numbers; it is commentary, not a strong view on markets.
- Mostly secondhand reporting (Reddit posts, press claims, a vendor table), with some primary data (SREBench design, objdiff loop, token audit), so treat the specific numbers as reported rather than independently verified.
