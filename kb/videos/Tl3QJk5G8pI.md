## Techniques
- **Two-stage sparse attention with a cheap indexer** — Compress history into learned summaries (about one entry per 4 tokens), score all summaries with a very cheap scorer against the current query, then run full attention only over the top-k (512 in DeepSeek's design). Other entries are skipped. *When:* Very long prompts (well above about 20k tokens) where most history is irrelevant to the current token. Avoid for short prompts, where the indexer is overhead, and for tasks that need every line, such as totals or cross-document consistency checks.
- **Multi-resolution context layout** — Keep the most recent ~128 tokens uncompressed, use a fine summary lane for mid-range history and a coarse summary lane (about one entry per 128 tokens) as a table of contents for the whole prompt, so nothing is fully invisible. *When:* When the model must see the full prompt but exact detail is only needed near the write position. This is a design idea from the video, not something the speaker tested.
- **Train with sparsity from the start, not prune afterward** — Train the model with the skipping mechanism enabled from day one so it learns to leave skimmable notes. The speaker contrasts this with pruning a finished dense model, which he says falls over. *When:* When designing or fine-tuning a model for long-context serving. Relevant to anyone choosing between architecture-level and post-hoc KV compression.
- **Stable prompt prefix for cache hits** — Keep the start of the prompt identical across requests so the provider can serve it from cache at a fraction of the input price. The speaker's ~40 cents per 100 turns figure assumes a stable cached corpus. *When:* Repeated long-context workloads over the same corpus, such as agent sessions over a fixed repo or doc set, where retrieval is the alternative.
- **Speculative decoding with a small draft model** — A small draft model guesses several tokens ahead, and the large model verifies them in one pass instead of generating each token itself. *When:* Latency- or cost-bound serving of a large model where a small same-family draft model is available.
