> Better Stack walks through Impeccable, a design-quality skill/toolchain that steers AI coding agents away from generic-looking sites, builds a homepage with it, and concludes it suits people who want good-looking output without deep design control, and that Claude Code is token-expensive for it.

## Summary
The host tests Impeccable, a design-quality toolchain that adds design knowledge (flagging 37 design anti-patterns) to an agent harness, and compares it to the Superpowers plugin but for design. The workflow runs teach (writes a product MD with purpose, brand, and principles), shape (produces a design brief), craft (builds the site in Astro and Tailwind), and document (writes a design MD with colors, typography, and CSS for later sessions). Because Claude Code has no image model, the host tricks Impeccable into using GPT Image 2 via an OpenAI key in the shell to generate three design probes, and picks option A. The crafted site looks impressive but has visible flaws, such as a tiny close button and an odd command layout. The "impeccable live" alpha then runs a dev server on the Astro site, where clicking an element in the browser opens a prompt box, so that a request like "make the text bigger" goes straight to the agent and edits the code. The verdict is that Impeccable is for people who want beautiful output without going deep into design, that precise tweaking is better done in a tool like Pencil, and that Claude Code burns many tokens because the product and design MD files are loaded into every subcommand, so Codex CLI or the Codex GUI (with native image generation and more generous limits) would likely be the better harness.

## Techniques
- **Staged design workflow with persistent design MD files** — In an empty project directory, run the teach subcommand and answer the product/brand, personality, reference-sites, and audience questions to produce a product MD. Run shape to get a design brief, then craft to build the site (Astro and Tailwind in the demo). Run document to write a design MD capturing colors, typography, and CSS, so a separate session can iterate without re-explaining the design. *When:* Starting a site or landing page from scratch with a coding agent, when you want design decisions kept across sessions. Expect the MD files to add token cost on every subcommand.
- **Forcing an image-model probe step when the harness has no image generation** — Tell the agent that an OpenAI key is already in the shell and to use GPT Image 2 to create the design probes. Pick among the generated variants (A/B/C) before the brief is written. *When:* Your harness (Claude Code in the demo) lacks an image tool but you still want visual exploration before committing to a design. The reviewer calls this a workaround; a harness like Codex would do it natively.
- **Browser-driven live iteration with impeccable live** — Run impeccable live in Claude Code. It installs scripts and starts a poll server against the Astro dev site. In the browser, click a section to open the pink overlay, choose bolder, quieter, or polish, or type a free-form request, then press Go. The prompt goes to the agent, which edits the source. *When:* Making many small, section-level visual fixes where describing the location in words would be slower than pointing at it. Alpha feature.
- **Run document after the visual pass** — Once the site looks right, run the document subcommand to write the design MD (colors, typography, CSS). Later sessions can read it instead of re-deriving the style. *When:* Before switching to a fresh session or another agent for tweaks, so the style stays consistent.

## Hot takes
- Impeccable suits someone who wants a beautiful result without deep design control; for precise positioning and border radius, use Pencil instead.
- Claude Code is probably not the best harness for Impeccable because the product and design MD files get loaded into every subcommand, and Claude models are expensive. The reviewer would rerun the test with Codex CLI or the Codex GUI.
- The GPT Image 2 probe step is a workaround for Claude Code's lack of an image model. Harnesses with native image generation do it automatically.
