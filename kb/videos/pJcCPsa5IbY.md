## Techniques
- **Wrap a frozen policy in a planner with memory (Harness VLA)** — Treat the pretrained VLA as a retriable contact-rich primitive. Put an LLM planner on top, with a small library of analytic primitives for non-contact moves (staging, free-space motion). Keep task memory of successful parameterized action traces for reuse, and global memory of reusable heuristics and failure models that persists across sessions. *When:* You must improve a pretrained policy that degrades under perturbation (object positions, lighting, multi-step tasks) without fine-tuning it. The same shape (retriable primitive + planner + episodic and cross-session memory) maps onto agent harnesses generally.
- **Publish every trial's trajectory for benchmark claims (Poolside)** — Release the full trace of every trial for every benchmark: each step, tool call and output. Host it at a stable URL so others can audit how a score was reached. *When:* Releasing or judging a model's benchmark claims. Full traces make a result checkable and cut down on cherry-picked numbers.
- **Thinking on/off ablation on the same benchmark** — Run the same agentic benchmark (Terminal-Bench 2.1) with thinking disabled and enabled, then compare. Poolside reports 60.4% vs 70.2%. *When:* Deciding whether reasoning tokens are worth the cost for a coding agent. Measure the delta before paying for thinking by default.
- **Agent optimizes its own harness in an automated research loop** — Let the coding agent profile and modify its own harness, then keep changes that improve speed or memory. Poolside reports 5.2% faster and 70% less memory allocation. *When:* Tuning your own agent harness. Treat it as a lead to reproduce: the evidence here is one vendor-reported session.
- **Fit check before running an image model locally** — Check peak inference memory (MageFlow: 18 to 20 GB), then compare it to your card (24 GB RTX 4090). Re-measure latency on the consumer card, because the vendor's speed numbers come from an A100. *When:* Sizing a local image generation or editing model for a single consumer GPU.
